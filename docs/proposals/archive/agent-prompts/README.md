# Archived external-agent relay prompts

These are the relay/handoff prompts written to hand a specific, now-**completed**
task to an external agent (Grok via Cursor/Twitter, a local Gemini supervisor, a
Codex handoff). They are kept as historical context — the work they drove has
landed and been verified in the fleet — but they are no longer active planning
docs, so they were moved out of `docs/proposals/` to declutter it.

Design/reference docs that merely *mention* an agent (e.g. `AGENT_LOOP_*`,
`prompt-context-management.md`) stayed in `docs/proposals/`; only single-use
relay prompts were archived here.

Moved 2026-09-11 (ledger D99). Nothing else changed; git history is intact
(`git log --follow`).
